# Aanchal Patel - Personal Portfolio Website

A modern, responsive, high-performance portfolio website built for **Aanchal Patel**, 1st Year B.Tech Computer Science & Engineering undergraduate at **JECRC University, Jaipur, Rajasthan**.

---

## 🌟 Key Features

- **Modern Aesthetic**: Futuristic obsidian dark-mode-first styling with electric cyan and racing red accents, glassmorphic cards, and soft ambient glow effects.
- **Theme Toggle**: One-click switch between Dark Mode and Light Mode, with automatic persistence in `localStorage`.
- **Dynamic Typewriter**: Hero title animated with role rotations (B.Tech CSE Student, Formula 1 Fan, District Basketball Athlete, Tech Explorer).
- **Core Sections**:
  - **Hero / Homepage**: Strong introduction, location badge, contact pills, and call-to-action buttons.
  - **About Me**: Narrative connecting computer science curiosity with passions for **Formula 1**, **travelling/exploring**, and **competitive basketball**.
  - **Education**: Detailed academic breakdown with **B.Tech CSE at JECRC University (1st Year)** and relevant learning areas (C/C++, Python, Web Basics, Data Structures, Computer Fundamentals).
  - **Skills & Competencies**: Categorized chips for Programming, Web Development, Developer Tools, and Interpersonal Leadership.
  - **Achievements Spotlight**: Featured showcase as a **District Basketball Player** emphasizing discipline, high-pressure agility, teamwork, and stamina.
  - **Passions & Inspirations**: Deep dive into Formula 1 telemetry/strategy and wanderlust exploration.
  - **Contact Section**: Phone card (`+91 9602008230`) with **1-click copy** and direct call, location (`Jaipur, Rajasthan`), social profiles, and interactive contact form with instant validation.
- **Responsive & Accessible**: Optimized for smartphones, tablets, laptops, and wide screens with a mobile navigation drawer.

## 🚀 How to Run Locally

### Option 1: Direct in Browser
Simply double-click `index.html` in your file explorer, or right-click and choose **Open with Google Chrome / Microsoft Edge / Brave / Firefox**.

### Option 2: Live Server (VS Code Extension)
1. Open this folder in **VS Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and click **"Open with Live Server"**.

### Option 3: Python Local Server
Run this command in PowerShell or Terminal inside the folder:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

## ✏️ How to Customize Your Links

Open `index.html` and search for:
1. **LinkedIn Profile**:
   Replace `https://www.linkedin.com` with your exact profile URL (e.g. `https://www.linkedin.com/in/your-username`).
2. **GitHub Profile**:
   Replace `https://github.com` with your exact profile URL (e.g. `https://github.com/your-username`).
3. **Email Address**:
   Replace `aanchalpatel.cse@gmail.com` with your personal or college email address if desired.
4. **Resume**:
   Place your PDF file (e.g., `Aanchal_Patel_Resume.pdf`) in this folder and link it in the hero buttons.

## 🌐 Free Deployment (Go Live in 2 Minutes)

### Via GitHub Pages:
1. Create a new repository on GitHub named `portfolio` or `<your-username>.github.io`.
2. Push these files (`index.html`, `styles.css`, `script.js`, `README.md`) to the repository.
3. Go to **Settings > Pages**. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your website will be live at `https://<your-username>.github.io/portfolio`!

### Via Vercel or Netlify:
1. Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub into [Vercel](https://vercel.com).
2. Instant global HTTPS deployment in 30 seconds.
